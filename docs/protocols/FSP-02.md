# FSP-02 - Distributed Attention

## Overview
**Duration**: 25 minutes  
**Family**: ATTN (Attention Architecture)  
**Intensity**: Medium  
**Experience Level**: Intermediate

## What This Session Is For
- Primary goal: strengthen deliberate control of narrow, wide, and switching attention.
- Protocol-specific aim: train attentional precision without over-efforting.
- Best use case: before cognitively demanding work, study, or focused meditation blocks.

## Session Methodology
Approach this like cognitive interval training: each phase asks for a specific attentional move, then consolidates it before the next shift.

### Phase Map
- Phase 1: **Anchor** (0:00-5:00) - Anchor awareness to breath and posture.
- Phase 2: **Distribute** (5:00-20:00) - Broaden attentional field while preserving stability.
- Phase 3: **Integrate** (20:00-25:00) - Organize insights and restore usable baseline function.

### Audio Stack
- `noise_bed`
- `binaural`
- `spatial_sweep`
- `pulse_cues`

## Mechanism (How It Influences State)
Layered auditory anchors plus phase-specific cue timing entrain attentional allocation and reduce drift.

In practical terms, the protocol combines:
- Repetition for state stabilization
- Gradual transitions to prevent abrupt overactivation
- Cue-based timing to guide attention, breath, and pacing

## Theory (Why This Design)
Based on attentional control training and state-dependent performance: repeated structured focus cycles improve voluntary allocation.

This is a training protocol, not a one-off effect. Benefits usually accumulate with repeated practice.

## What Listeners Typically Notice
- Early response: attention narrows and stabilizes with less distractor pull.
- Mid-session shift: tracking becomes flexible between focal and peripheral channels.
- End-state: task handoff feels cleaner with reduced cognitive lag.

## Usage Guidelines
- Use stereo headphones at conservative volume.
- Keep posture stable and jaw/shoulders relaxed.
- If agitation increases, reduce volume and return to natural breathing.
- Prefer regular practice (several sessions/week) over intensity spikes.
- Treat lapses as reps. Notice drift, return cleanly, and continue without self-critique.
