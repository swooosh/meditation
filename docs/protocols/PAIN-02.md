# PAIN-02 - Sensation Reframe

## Overview
**Duration**: 20 minutes  
**Family**: PAIN (Pain Modulation)  
**Intensity**: Medium  
**Experience Level**: Intermediate

## What This Session Is For
- Primary goal: reduce pain dominance in awareness and improve functional agency.
- Protocol-specific aim: shift from threat interpretation toward workable sensory mapping.
- Best use case: discomfort episodes where attention-based modulation is appropriate.

## Session Methodology
Use precision rather than suppression: the aim is changing relationship to sensation, not denying it exists.

### Phase Map
- Phase 1: **Baseline** (0:00-5:00) - Map current state clearly before modulation.
- Phase 2: **Reframe** (5:00-15:00) - Reinterpret sensation through context and attentional control.
- Phase 3: **Integrate** (15:00-20:00) - Organize insights and restore usable baseline function.

### Audio Stack
- `noise_bed`
- `binaural`
- `pulse_cues`
- `harmonic_pad`

## Mechanism (How It Influences State)
Attentional redirection and reinterpretation cues modulate subjective intensity by changing signal appraisal.

In practical terms, the protocol combines:
- Repetition for state stabilization
- Gradual transitions to prevent abrupt overactivation
- Cue-based timing to guide attention, breath, and pacing

## Theory (Why This Design)
Aligned with cognitive and attentional pain models: perception is influenced by attention, context, and interpretation.

This is a training protocol, not a one-off effect. Benefits usually accumulate with repeated practice.

## What Listeners Typically Notice
- Early response: signal intensity may feel less dominant.
- Mid-session shift: attention can move from threat to workable sensation.
- End-state: reappraisal at the end improves tolerance and agency.

### This Session Timeline
- Baseline (0:00-5:00): map current state clearly before modulation.
- Reframe (5:00-15:00): reinterpret sensation through context and attentional control.
- Integrate (15:00-20:00): organize insights and restore usable baseline function.

## Usage Guidelines
- Use stereo headphones at conservative volume.
- Keep posture stable and jaw/shoulders relaxed.
- If agitation increases, reduce volume and return to natural breathing.
- Prefer regular practice (several sessions/week) over intensity spikes.
- Pair this with your existing clinical plan; this protocol is adjunctive, not a replacement for care.
