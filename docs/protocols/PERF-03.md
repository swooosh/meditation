# PERF-03 - Micro-Dose Focus

## Overview
**Duration**: 5 minutes  
**Family**: PERF (Performance State)  
**Intensity**: Medium  
**Experience Level**: Intermediate to Advanced

## What This Session Is For
- Primary goal: arrive in a calm-alert performance state on demand.
- Protocol-specific aim: reduce noise, sharpen decision bandwidth, and stabilize execution readiness.
- Best use case: 5-20 minutes before presentations, competition, negotiations, or critical conversations.

## Session Methodology
Use this as pre-mission calibration: downshift excess arousal first, then lock in task-relevant activation.

### Phase Map
- Phase 1: **Ramp** (0:00-3:00) - Increase activation gradually while maintaining control.
- Phase 2: **Peak** (3:00-5:00) - Guide a stable transition toward the protocol target state.

### Audio Stack
- `noise_bed`
- `binaural`
- `pulse_cues`

## Mechanism (How It Influences State)
Low-frequency stabilization, then moderate activation cues, shape autonomic tone toward calm-alert balance.

In practical terms, the protocol combines:
- Repetition for state stabilization
- Gradual transitions to prevent abrupt overactivation
- Cue-based timing to guide attention, breath, and pacing

## Theory (Why This Design)
Follows Yerkes-Dodson-style arousal optimization: not maximum arousal, but precise arousal for the task.

This is a training protocol, not a one-off effect. Benefits usually accumulate with repeated practice.

## What Listeners Typically Notice
- Early response: state shifts from diffuse to calm-alert readiness.
- Mid-session shift: decision speed increases while urgency feels lower.
- End-state: a stable pre-action lock-in without jitter.

### This Session Timeline
- Ramp (0:00-3:00): increase activation gradually while maintaining control.
- Peak (3:00-5:00): guide a stable transition toward the protocol target state.

## Usage Guidelines
- Use stereo headphones at conservative volume.
- Keep posture stable and jaw/shoulders relaxed.
- If agitation increases, reduce volume and return to natural breathing.
- Prefer regular practice (several sessions/week) over intensity spikes.
- End with a clear task intention so state transfer is immediate when you begin the real event.
