# META-02 - Witness Perspective

## Overview
**Duration**: 30 minutes  
**Family**: META (Self-Model Exploration)  
**Intensity**: Medium  
**Experience Level**: Intermediate

## What This Session Is For

- Protocol-specific aim: explore self-model flexibility without dissociative drift.
- Best use case: contemplative practice windows with quiet integration afterward.

## Mechanism (How It Influences State)
Reduced narrative load and stable anchors support decentering from self-referential thought patterns.

In practical terms, the protocol combines:
- Repetition for state stabilization
- Gradual transitions to prevent abrupt overactivation
- Cue-based timing to guide attention, breath, and pacing

## Theory (Why This Design)
Informed by contemplative metacognition models: observer perspective reduces identification with transient cognitive content.

This is a training protocol, not a one-off effect. Benefits usually accumulate with repeated practice.
